Sprachmemo-Transkription

Empfangene WhatsApp-Sprachnachrichten werden auf deinem Heimserver transkribiert und von Claude in Stichpunkte gefasst.

Backend

Ohne abschließenden Slash, z. B. https://fherrmann.com/whisper. Muss per HTTPS erreichbar sein.

Muss exakt dem AUTH_TOKEN in der .env auf dem Server entsprechen. Der Anthropic-Key gehört nicht hierher — der bleibt auf dem Server. 


    


    

      
Verhalten


      

      

      
      
      
Höher lohnt nur, wenn der Server mehrere Transkriptionen gleichzeitig verkraftet.


      
    


    

      
Zwischenspeicher

      

        Fertige Transkripte liegen lokal, damit dieselbe Nachricht nie zweimal
        verarbeitet wird. Der Server hält zusätzlich einen eigenen Cache.
